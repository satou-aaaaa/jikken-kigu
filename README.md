# 実験器具あて（jikken-kigu）

ガスバーナーやはかる器具の使い方（青い炎にするねじ・最後に閉じるもの・液面を読む器具 など）を読んで、ガス調節ねじ・空気調節ねじ・元栓・メスシリンダー・上皿てんびんを当てる1日5問の学習ゲーム。正解したら「何をするもの？」（炎を調節する・ガスを出す／止める・はかる）も選ぶ。中学1年理科「実験器具の使い方」。

遊ぶ: <https://satou-aaaaa.github.io/jikken-kigu/>

- 中身は香川県教育委員会の補充プリント、横浜市立境木中学校の学習課題、宮城県総合教育センターの授業案、大阪市立中学校のドリルプリント、埴生中学校の理科基礎シートで確かめたことだけです。
- 家でガスバーナーを使ったりしないでください。顕微鏡は「顕微鏡の部品あて」で扱います。このゲームは教科書の代わりではありません。くわしくは教科書で確かめてください。
